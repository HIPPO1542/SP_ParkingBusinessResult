# Các tác vụ dự kiến

- Xem dữ liệu kinh doanh theo thời gian, thêm, sửa, xóa và import (UC 1.5).
- Danh sách, xem tổng hợp và xuất báo cáo (UC 3.4).
- Các tác vụ phân tích khác cần đối chiếu với nguồn dữ liệu.

Các thao tác thử nghiệm thêm, sửa, xóa, danh sách và chi tiết đã có command hoặc query cùng handler riêng. Import, xem theo thời gian và các API báo cáo theo đặc tả chưa hoàn thành. Các handler hiện được controller gọi qua dependency injection, chưa dùng MediatR.
