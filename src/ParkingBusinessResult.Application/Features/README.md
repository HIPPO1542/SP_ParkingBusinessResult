# Các tác vụ dự kiến

- Xem dữ liệu kinh doanh theo thời gian, thêm, sửa, xóa và import (UC 1.5).
- Danh sách, xem tổng hợp và xuất báo cáo (UC 3.4).
- Các tác vụ phân tích khác cần đối chiếu với nguồn dữ liệu.

Mỗi tác vụ sẽ có command hoặc query và handler riêng; chưa có handler hoặc endpoint hoạt động.
